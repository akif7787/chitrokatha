# 🎬 ChitroKatha (চিত্রকথা) - বাংলা ও বিশ্ব সিনেমা

> **অনলাইনে সিনেমা দেখার চমৎকার প্ল্যাটফর্ম** — বাংলা ও বিশ্ব সেরা চলচ্চিত্র, এইচডি ট্রেলার, লাইভ এপিআই, ওয়াচলিস্ট এবং সিনেমা আবিষ্কারের আধুনিক অভিজ্ঞতা।

---

## 🌟 ওভারভিউ (Overview)

**ChitroKatha (চিত্রকথা)** হলো বাংলা এবং আন্তর্জাতিক চলচ্চিত্রের জন্য নির্মিত একটি প্রিমিয়াম সিনেমা আবিষ্কার ও স্ট্রিমিং ইন্টারফেস। এখানে বাংলা ক্লাসিক, সমকালীন ব্লকবাস্টার, নাটক, ওয়েব সিরিজ এবং বিশ্ব চলচ্চিত্রের এক সমৃদ্ধ সংগ্রহ পাওয়া যাবে সম্পূর্ণ দ্বিভাষিক (বাংলা ও ইংরেজি) অভিজ্ঞতায়।

---

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Key Features)

- 🎭 **দ্বিভাষিক অভিজ্ঞতা (Bilingual Support)**: বাংলা এবং ইংরেজি ভাষায় সম্পূর্ণ ইন্টারফেস ও সিনেমা তথ্য।
- 🎥 **বহুমাত্রিক ক্যাটাগরি**:
  - বাংলা সিনেমা (ঢালিউড ও টলিউড)
  - বাংলা নাটক ও টেলিফিল্ম
  - প্রিমিয়াম ওয়েব সিরিজ
  - হলিউড, বলিউড এবং বিশ্ব সিনেমা
- 🔥 **ট্রেন্ডিং টপ ১০ ও রিকমেন্ডেশন**: জনপ্রিয় সিনেমার লাইভ র‍্যাঙ্কিং ও কিউরেটেড তালিকা।
- 🎬 **অভিনেতা ও ফিল্মোগ্রাফি সেকশন**: প্রিয় তারকাদের প্রোফাইল এবং তাদের কাজের বিস্তারিত তালিকা।
- 🍿 **সিনেমাটিক ট্রেলার ও ভিডিও প্লেয়ার**: অন্তর্নির্মিত এইচডি ভিডিও প্লেয়ার এবং ট্রেলার ভিউয়ার।
- 📌 **ওয়াচলিস্ট ও ফেভারিটস**: ব্যক্তিগত পছন্দ সংরক্ষণ ও পরবর্তীতে দেখার সুবিধা।
- ⭐ **রেটিং ও রিভিউ সিস্টেম**: ব্যবহারকারীদের রেটিং ও ফিডব্যাক।
- 🔍 **স্মার্ট সার্চ ও ফিল্টার**: জঁরা, বছর, ইন্ডাস্ট্রি ও টাইটেল অনুযায়ী দ্রুত অনুসন্ধান।
- 📡 **Watchmode API ইন্টিগ্রেশন**: লাইভ স্ট্রিমিং সোর্স এবং আন্তর্জাতিক প্ল্যাটফর্ম ট্র্যাকিং।
- 📱 **রেসপনসিভ ও পিডব্লিউএ (PWA)**: মোবাইল, ট্যাবলেট এবং ডেস্কটপে ফ্লুইড অভিজ্ঞতা এবং অফলাইন ক্যাশিং।

## 🛠️ টেক স্ট্যাক (Tech Stack)

- **Frontend**: [React 19](https://react.dev/), [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Motion](https://motion.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **APIs**: Watchmode API, Custom Movie Storage

## 🚀 লোকাল সেটআপ (Local Setup)

### পূর্বশর্ত:
- [Node.js](https://nodejs.org/) (v18+)
- npm / yarn / bun

### ইন্সটলেশন ধাপসমূহ:

1. **রিপোজিটরি ক্লোন করুন:**
   ```bash
   git clone https://github.com/akif7787/chitrokatha.git
   cd chitrokatha
   ```

2. **ডিপেন্ডেন্সি ইন্সটল করুন:**
   ```bash
   npm install --legacy-peer-deps
   ```

3. **ডেভেলপমেন্ট সার্ভার চালু করুন:**
   ```bash
   npm run dev
   ```

4. **প্রোডাকশন বিল্ড তৈরি করুন:**
   ```bash
   npm run build
   ```
